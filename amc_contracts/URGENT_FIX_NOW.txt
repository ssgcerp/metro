CAUSE: The database column "branch_code" does not exist, but Odoo is trying to access it.

SOLUTION: Add the Column NOW
================================================================================

OPTION 1: Using pgAdmin (Easiest)
----------------------------------

1. Open pgAdmin
2. Connect to PostgreSQL server
3. Navigate to: Servers → Databases → metro1
4. Right-click "metro1" → Query Tool
5. Copy and paste this SQL:

   ALTER TABLE res_company ADD COLUMN IF NOT EXISTS branch_code VARCHAR(10);

6. Click Execute (F5)
7. You should see: "ALTER TABLE" (success)
8. Close pgAdmin

9. ⚠️ IMPORTANT: RESTART Odoo server completely
10. Refresh your browser (Ctrl+F5)

================================================================================

OPTION 2: Using PowerShell Script
---------------------------------

1. Right-click "add_column_script.ps1" in this folder
2. Select "Run with PowerShell"
3. Enter your PostgreSQL password when prompted
4. RESTART Odoo server
5. Refresh browser

================================================================================

OPTION 3: Command Line
----------------------

Open PowerShell or Command Prompt and run:

   psql -U odoo -d metro1 -c "ALTER TABLE res_company ADD COLUMN IF NOT EXISTS branch_code VARCHAR(10);"

Enter password when prompted, then RESTART Odoo.

✅ The error will be GONE
