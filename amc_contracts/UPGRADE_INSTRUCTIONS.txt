================================================================================
FIX FOR: Field "is_cancelled_stage" does not exist error
================================================================================

This error happens because Odoo validates views before models are fully reloaded.

SOLUTION:
---------

Option 1: Restart Odoo Server First (Recommended)
-------------------------------------------------
1. STOP Odoo server completely
2. START Odoo server again
3. Then upgrade the module (Apps → AMC Contracts → Upgrade)

Option 2: Upgrade via Command Line
-----------------------------------
If Option 1 doesn't work:
1. Stop Odoo server
2. Run: python odoo-bin -u amc_contracts -d metro1
3. Start Odoo server

The field IS defined in the model - it just needs Odoo to reload Python models first.

================================================================================
