ERROR: column res_company.branch_code does not exist

SOLUTION: Run this SQL command in your PostgreSQL database:

    ALTER TABLE res_company ADD COLUMN IF NOT EXISTS branch_code VARCHAR(10);

================================================================================
HOW TO RUN:
================================================================================

METHOD 1: Using pgAdmin (Easiest)
---------------------------------
1. Open pgAdmin application
2. Connect to your PostgreSQL server
3. Navigate to: Servers → PostgreSQL → Databases → metro1 (your database name)
4. Right-click on "metro1" → Query Tool
5. Copy and paste this SQL:
   
   ALTER TABLE res_company ADD COLUMN IF NOT EXISTS branch_code VARCHAR(10);

6. Click Execute button (or press F5)
7. You should see: "ALTER TABLE" message
8. Close pgAdmin
9. RESTART your Odoo server completely
10. Refresh your browser

METHOD 2: Using Command Line (psql)
-----------------------------------
1. Open Command Prompt or PowerShell
2. Navigate to PostgreSQL bin directory (usually: C:\Program Files\PostgreSQL\12\bin)
3. Run:
   
   psql -U odoo -d metro1 -c "ALTER TABLE res_company ADD COLUMN IF NOT EXISTS branch_code VARCHAR(10);"

4. Enter your PostgreSQL password when prompted
5. RESTART your Odoo server
6. Refresh your browser

METHOD 3: Using Python Script (Alternative)
-------------------------------------------
1. Edit fix_branch_code.py and update database credentials
2. Run: python fix_branch_code.py
3. RESTART your Odoo server
4. Refresh your browser

================================================================================
IMPORTANT: After running SQL
================================================================================

1. RESTART your Odoo server completely (stop and start)
2. Clear browser cache or do hard refresh (Ctrl+F5)
3. The error should be resolved

================================================================================
VERIFICATION
================================================================================

To verify the column was created, run:
    SELECT column_name FROM information_schema.columns 
    WHERE table_name='res_company' AND column_name='branch_code';

If it returns a row, the column exists and you're good to go!
